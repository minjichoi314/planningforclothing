# 의복 마련 계획 보드게임

한국어 학습용 웹앱. 첨부 예시의 종이·클립·초록색 학습 카드 분위기를 CSS로 재구성했습니다.

## 기능

- 학년·반·번호·이름으로 참가자 카드 시작. 계정 인증 기능은 아닙니다.
- STEP 1 필요성, 2 예산, 3 활용도, 4 소재, 5 관리 가능성, FINAL 종합 미션. 각 단계 조사 질문 3개, 완료당 5점, 총 30점.
- 지속가능성 BONUS는 점수에서 제외.
- 10개 직업 관점 중 하나를 선택하여 AI 피드백 요청, 성찰, 계획 수정·보완.
- 브라우저 `localStorage` 자동 저장. 마지막에 브라우저 인쇄 창의 **PDF로 저장** 사용.

## 실행

Node.js 20 이상에서:

```bash
cp .env.example .env
# .env에 OPENAI_API_KEY를 입력하고, 셸에서 환경 변수로 로드합니다.
set -a; . ./.env; set +a
npm start
```

`http://localhost:3000`에 접속합니다. 배포 환경에서는 호스팅 서비스의 비밀 환경 변수에 `OPENAI_API_KEY`를 설정하세요. `.env`는 Git에 올리지 마세요. API 키가 없어도 미션 기록은 동작하지만 실제 AI 피드백은 생성할 수 없으므로 완료 PDF 단계까지 진행할 수 없습니다. 정적 GitHub Pages만으로는 서버 API가 동작하지 않습니다. GitHub에는 이 저장소를 올리고 Node 서버를 지원하는 호스팅에 배포하세요.

## 개인정보와 평가

학생 입력은 현재 브라우저에 저장됩니다. 공용 기기에서는 브라우저 사이트 데이터를 삭제하세요. AI 요청에는 학생 이름·학년·반·번호를 넣지 않으며, 미션 답변에 학생 스스로 개인정보를 적지 않도록 지도하세요. 답변이 10자 이상인지에 따른 5점은 활동 완료 표시이며, 답변의 사실 확인·내용 평가는 교사가 맡습니다. AI 응답은 검증이 필요한 조언입니다.

## 프로젝트 구조

- `server.js`: 정적 파일 제공과 서버 측 AI API 호출
- `public/index.html`, `public/styles.css`, `public/app.js`: 화면과 보드 게임
- `test/server.test.js`: 요청 검증 테스트
